# 更新日志

## 未发布

AI 记账改成对话式助手，抽屉和 `/ai` 是同一条对话。

**改动**
- 记账、提问都在一个输入框里说，草稿卡插在对话里；缺字段时只问一句，补一句就更新草稿
- 草稿卡默认只读，点「修改」才展开表单；底部「入账 / 忽略」，全部一起入账用「确认入账（N）」
- 去掉示例标签行、「解析」按钮、模型和耗时显示、独立的「问问 AI」区块、「在完整页面打开」

## v1.2.0（2026-10-30）

AI 记账升级成随身助手。

**新增**
- 顶栏「AI 记账」打开全局抽屉：桌面在右侧，可拖宽；手机是全屏 sheet，可下拉收起。切换页面不关，草稿保留
- `/ai` 保留为完整模式，抽屉里可以「在完整页面打开」，草稿一起带过去
- 列表上的 `@`：流水、账户、持仓、资产、借贷都能引用，可以说「把这笔改成餐饮」「这笔还信用卡」「还了 2000」
- 抽屉带上当前页和筛选。「这笔」的解析顺序：明确说的 > `@` 引用的 > 当前页筛选 > 不确定就问
- 草稿卡单独「入账」；抽屉里解析新内容时接在未入账的草稿后面，不再覆盖

**修复**
- 重复入账：草稿落到服务端，连点、并发、重新解析出同样内容都只记一笔，并提示「这笔刚才已记过」。60 秒后同样内容算新的一笔；一次多笔里两笔一样的账都会记
- 串账：写流水时校验账户和科目属于当前用户
- 手机上不再显示 ⌘V、⌘+Enter

**其他**
- 新增测试套件 `backend/test/`，`npm test` 不需要模型
- 版本号对齐：`VERSION` 之前还是 1.0.0，和 `yh-app.json` 不一致
